# 🎂 McdBirthdayButler（麦麦生日会管家）

> 一位懂麦当劳、更懂孩子的生日派对管家：一句"孩子 X 岁、Y 个小朋友、预算 Z 元、X 月 X 日、在 C 城区"，即可完成从「哪能办 → 哪天有 → 多少钱 → 下单确认」的全流程规划。

## 📖 项目介绍

家长想给 3-10 岁的孩子在麦当劳办一场生日会，通常卡在三个问题：**哪些门店能办？有哪些场次？怎么收费？**

McdBirthdayButler 是一个基于麦当劳 MCP（mcd-mcp）的 Skill，把派对查询与下单的完整调用链封装为「管家式」对话体验：

- ✅ **全流程托管**：城市确认 → 门店筛选 → 日期/场次查询 → 方案对比 → 确认下单，一气呵成；
- ✅ **一次性追问**：缺城市、日期、人数、预算时，一条消息问齐，绝不挤牙膏式提问；
- ✅ **方案表格对比**：推荐 2-3 个「门店 + 场次 + 价格」候选方案，表格呈现距离、时间、价格、剩余名额；
- ✅ **管家点评**：每个方案一句真人管家式点评（如"工作日下午场，人少不吵，性价比高"），并给出明确倾向但不替用户拍板；
- ✅ **下单安全红线**：创建订单前必须展示完整订单确认单，并获得用户明确肯定指令，**绝不未确认就下单**；
- ✅ **数据忠实**：门店编码、场次、价格、余位全部来自 MCP 工具真实返回，不编造、不"大概"。

### 目标用户

| 用户 | 场景 |
|---|---|
| 3-10 岁孩子的家长 | 主用户：想办生日会但没有精力逐店打电话咨询 |
| 二胎/多孩家庭 | 需要对比包场 vs 拼团性价比 |
| 幼儿园/兴趣班家委会 | 集体生日会，重视场次余位与成团人数规则 |
| 给孩子张罗派对的长辈 | 需要亲切、低门槛的对话式引导 |

## 🛠 安装方法

### 前置条件：申请麦当劳 MCP Token

1. 打开麦当劳 MCP 开放平台 <https://open.mcd.cn/mcp>（或活动仓库指引的申请入口）；
2. 手机号登录后进入「控制台」，点击「激活」申请 MCP Token，同意服务协议；
3. 复制生成的 Token（注意妥善保管，不要提交到 Git 仓库）。

### 第一步：配置麦当劳 MCP Server

在 WorkBuddy 中：左侧边栏【专家·技能·连接器】→【连接器】→ 右上角【自定义连接器】→【配置 MCP】，填入以下 JSON（**替换 `YOUR_MCP_TOKEN`** 为实际 Token）：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_TOKEN"
      }
    }
  }
}
```

保存后，回到连接器列表将 **mcd-mcp 启用**。其他 MCP Client（Cherry Studio / Cursor / Trae / VSCode 等）按各自文档导入同样的 JSON 即可。

### 第二步：安装本 Skill

**WorkBuddy 用户：**

1. 下载/克隆本仓库：
   ```bash
   git clone https://github.com/<your-name>/mcd-birthday-butler.git
   ```
2. 将整个 `mcd-birthday-butler` 文件夹放入技能目录：
   - 个人使用：`~/.workbuddy/skills/mcd-birthday-butler/`
   - 团队共享：`<工作区>/.workbuddy/skills/mcd-birthday-butler/`
3. 重启会话，Skill 即可被自动触发。

**其他支持 Skill/系统提示词的 Client：** 将 `SKILL.md` 正文作为系统提示词或自定义指令注入，并确保 mcd-mcp 已连接。

## 💬 使用示例

### 示例 1：一句话启动全流程

> **用户**：我想在麦当劳给女儿办个生日会，她 6 岁，8 个小朋友，预算 1500 元，10 月 18 号，杭州滨江区附近。
>
> **管家**：收到！6 岁、8 位小朋友、预算 1500 元、10 月 18 日、滨江——齐活，这就帮你查杭州能办生日会的门店和当天场次。
>
> （管家依次调用：派对商品确认 → 城市确认 → 门店筛选 → 日期/场次查询）

### 示例 2：方案对比与管家点评

> **管家**：杭州支持生日会，滨江找到 3 家有 10 月 18 日场次的门店：
>
> | 项目 | 方案 A | 方案 B | 方案 C |
> |---|---|---|---|
> | 门店 | 滨江宝龙城餐厅 | 滨江天街餐厅 | 江南大道餐厅 |
> | 场次 | 14:00-16:00 | 10:00-12:00 | 14:00-16:00 |
> | 类型 | 包场 | 包场 | 拼团 |
> | 价格 | ¥1680 | ¥1888 | ¥98/人 ×8 ≈ ¥784 |
> | 剩余名额 | 全场 | 全场 | 12/20 |
> | 距离 | 约 2.1 km | 约 3.4 km | 约 5.0 km |
>
> - 方案 A：周六黄金档包场，全归你们，热闹不拼人。
> - 方案 B：上午场孩子状态最好，不耽误午睡。
> - 方案 C：性价比最高，但要等其他家庭拼团。
>
> 8 个小朋友、预算 1500，我更推荐**方案 A**：拼团虽然有变数，但 1500 的预算够你们直接锁定包场，最省心。选哪个？

### 示例 3：信息不全时一次性追问

> **用户**：想在麦当劳办个生日会。
>
> **管家**：好嘞！帮你规划前，四个信息一次发我即可：
> ① 城市/城区 ② 想要的日期 ③ 小朋友人数 ④ 大概预算。

### 示例 4：下单前的订单确认单（安全红线）

> **管家**：
> **订单确认单** ✅ 请核对
>
> | 项目 | 内容 |
> |---|---|
> | 派对主题 | 麦麦生日会（SPU：100xxx） |
> | 派对类型 | 包场（partyType=1） |
> | 城市 | 杭州（code: 330100） |
> | 门店 | 滨江宝龙城餐厅（storeCode: XXXX） |
> | 日期 | 2026 年 10 月 18 日（周六） |
> | 场次 | 14:00-16:00（场次 ID：xxx，余位：全场） |
> | 人数 | 8 人 |
> | 预估总价 | ¥1680 |
>
> 回复"**确认下单**"即可锁定名额；需要修改请直接说。

> ⚠️ 注：以上门店、价格、场次均为示例，实际以 MCP 工具实时返回为准。

## 🧩 与麦当劳 MCP 的关系

本 Skill 不引入任何新的后端服务，全部能力来自麦当劳官方 MCP Server（`https://mcp.mcd.cn`）的派对工具族：`mall-points-products` / `mall-product-detail` / `query-party-city` / `query-party-store` / `query-party-store-date` / `query-party-store-session` / `party-order-create`，辅以 `now-time-info`（日期校验）与 `calculate-price`（加购核价）。完整调用链与业务价值详见 [MCP_INTEGRATION.md](./MCP_INTEGRATION.md)。
